# ⚡ Flow Automation - Chrome Extension (v1.6.0)

> Automated multi-prompt batch generator with hardware-level Enter (`isTrusted: true`), round-robin prompt division, human jitter timing, and completion sound alerts for Google Flow (`flow.google.com`).

---

## 🚀 1-Time Setup (Takes 30 Seconds):
1. Open Google Chrome and visit: `chrome://extensions`
2. Top right corner me **"Developer mode"** toggle ON karein.
3. Top left corner me **"Load unpacked"** button par click karein.
4. Ye folder select karein (`picmaze-flow-worker`):
   ```
   tools/picmaze-flow-worker
   ```
5. Chrome toolbar me extension pin kar lein!

---

## 🎯 Daily Usage & Features:
1. Browser me **Google Flow** (`flow.google.com`) open karein.
2. Extension icon click karein:
   - **Prompts**: `+ Add Prompt` par click karke apne 1 se 10 prompts enter karein.
   - **Batch Count**: Total kitne generations karne hain (e.g. `10` ya `20`).
   - **Interval**: Base seconds delay (e.g. `15s`).
   - **Sound Chime**: Completion alert switch (enabled by default).
3. Click **[▶ START MULTI-PROMPT BATCH]**.
4. Script automatically har prompt ko fair round-robin tareeqe se alternate karegi, human-like jitter timing add karegi, aur batch khatam hone par sweet **Chime Beep** bajayegi!
